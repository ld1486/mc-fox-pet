Fox Desk — a Minecraft fox that lives on your desktop
=====================================================

1. Unzip the whole folder somewhere (do not run it from inside the zip).
2. Double-click  "Install shortcut (安装快捷方式).cmd".
   It copies the app to  %LOCALAPPDATA%\Programs\Fox Desk  and creates
   Desktop + Start Menu shortcuts. No admin rights needed.
3. Start it from the shortcut. First run opens Settings: paste your
   OpenAI-compatible API key (DeepSeek, Kimi, Qwen, local Ollama ...).
   The key never leaves this machine.

Why not a normal installer?
  Windows 11 "Smart App Control" refuses unsigned executables. This bundle
  keeps the original signed Electron binary and only copies files, so it
  starts on those machines too.

The fox
  - 4 skins: red fox / snow fox / red cub / snow cub (right-click the fox).
  - Click to pet, drag to move, double-click to spin, right-click for the menu.
  - Size slider and two camera sliders (left-right, up-down) in the hover bar.
    Only the fox changes size - the buttons never move.
  - Mouth items: right-click > "Holding" to give it an emerald, chicken, wheat...
  - Optional gravity: it falls and lands on the taskbar.
  - Idle animations: breathing, tail wag, blink, look around, sit, scratch,
    groom, stretch, pounce, spin, pace, and a nap when you leave it alone.

The desk (right-click > "Fox Desk", or Ctrl+Shift+Space)
  - Write: paste your draft, pick an action (continue / expand / shorten /
    polish / more natural / more formal / title / outline / advice / ending /
    opening), watch it stream, copy with one click.
  - Replies: paste a WeChat/QQ conversation, pick who you are talking to,
    and get a few lines you can send as-is.
  - Chat with fox: just talk to the fox. It remembers the conversation.
  - English / 中文: switch inside Settings (or use the English installer).

Hotkeys
  Ctrl+Shift+Space  open the desk with the clipboard text, on the replies tab
  Ctrl+Shift+W      open the desk on the writing tab
  Ctrl+Shift+F      hide / show the fox

Uninstall
  Double-click "卸载.cmd" (Uninstall.cmd) inside the installed folder, or
  Settings > Apps > Fox Desk. Your settings stay in %APPDATA%\mc-fox-pet.
