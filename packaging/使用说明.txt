狐狸书桌 · Minecraft 狐狸桌宠  v1.0.0
=========================================

这是一个免安装的绿色包（用系统里已签名的 Electron 作为启动器，
所以在开着「智能应用控制」的 Windows 11 上也能跑）。

安装（会建快捷方式）：
  1. 右键这个压缩包 → 全部解压（一定要先解压，别在压缩包里直接双击）
  2. 双击「安装快捷方式.cmd」
  3. 桌面和开始菜单就会出现「狐狸书桌」

想直接试用、不安装：
  双击文件夹里的 electron.exe 即可（狐狸会直接出现在桌面上）。

第一次打开会自动弹出「设置」页，填上 API Key 才能用写作和聊天：
  - 接口地址：https://api.deepseek.com/v1
  - 模型：deepseek-chat
  - Key：https://platform.deepseek.com 申请
  也支持任何 OpenAI 兼容服务（Kimi、通义、本地 Ollama 等）。

常用操作：
  - 点狐狸：摸头 / 爱心     双击：转圈
  - 按住拖动：搬家          右键：菜单（换皮肤、大小、睡觉、退出）
  - Ctrl+Shift+Space：复制别人的聊天内容后按，狐狸给出可发送的回复
  - Ctrl+Shift+W：带着剪贴板内容打开写作页
  - Ctrl+Shift+F：把狐狸藏起来 / 叫出来

卸载：双击程序目录里的「卸载.cmd」，
      或 设置 → 应用 → 已安装的应用 → 狐狸书桌。
      （聊天/写作配置保留在 %APPDATA%\mc-fox-pet，想彻底清掉手动删这个文件夹）

如果 Windows 提示「智能应用控制已阻止此应用」，请用上面的绿色包方式安装，
或者用另一个 fox-desk-setup-1.0.0.exe 安装包（它需要系统允许未签名程序）。
